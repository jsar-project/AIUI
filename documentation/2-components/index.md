# 组件

AIUI 提供一组内置 UI 组件，用于通过 WXML 构建界面。

## View Containers

- [View](/AIUI/components/view)：基础容器组件；`row`、`column` 和 `fragment` 使用相同的容器实现。
- [ScrollView](/AIUI/components/scroll-view)：支持横向或纵向滚动的视图容器。
- [Swiper](/AIUI/components/swiper)：使用 `swiper` 与 `swiper-item` 组织分页内容。
- [Card](/AIUI/components/card)：组合封面、标题、正文和页脚。

## Date Components

- [Calendar](/AIUI/components/calendar)：用于展示月份、周和日程信息的日历组件。

## Basic Content

- [Text](/AIUI/components/text)：用于显示纯文本内容。
- [Icon](/AIUI/components/icon)：使用文本字体绘制图标。
- [ErrorState](/AIUI/components/error-state)：用于展示空状态、异常状态或错误提示。
- [Streamdown](/AIUI/components/streamdown)：支持流式渲染的 Markdown 内容组件。
- [Table](/AIUI/components/table)：根据列定义和行数据绘制表格。
- [TimedText](/AIUI/components/timed-text)：突出与播放进度同步的文本片段。

## Semantic Content

- [P](/AIUI/components/p)：组织段落和行内内容。
- [Header](/AIUI/components/header)：展示内容标题。
- [Blockquote](/AIUI/components/blockquote)：展示引用内容。
- [List](/AIUI/components/list)：组织列表项。
- [ListItem](/AIUI/components/list-item)：展示单个列表项。
- [B](/AIUI/components/b)：标记粗体内容。
- [I](/AIUI/components/i)：标记斜体内容。
- [Snippet](/AIUI/components/snippet)：展示行内或块级代码。
- [Formula](/AIUI/components/formula)：展示行内或块级数学公式。

## Form Components

- [Button](/AIUI/components/button)：可点击的按钮组件。
- [Input](/AIUI/components/input)：单行文本输入框。
- [Textarea](/AIUI/components/textarea)：多行文本输入框。
- [Switch](/AIUI/components/switch)：开关和复选框控件。

## Media Components

- [Image](/AIUI/components/image)：用于显示图片内容。
- [Video](/AIUI/components/video)：播放视频并响应播放事件。
- [LottieView](/AIUI/components/lottie-view)：用于渲染 Lottie 动画资源。

## Location Components

- [Map](/AIUI/components/map)：使用 MVT 瓦片绘制地图。

## Canvas & Chart

- [Canvas](/AIUI/components/canvas)：提供 2D 绘图上下文和自定义绘制能力。
- [Chart](/AIUI/components/chart)：用于渲染数据可视化图表。

## AI Components

- [A2UI](/AIUI/components/a2ui)：根据 Agent 输出的结构化命令生成界面。
