# Components

AIUI provides built-in UI components for constructing interfaces with WXML.

## View Containers

- [View](/AIUI/components/view): A basic container; `row`, `column`, and `fragment` use the same container implementation.
- [ScrollView](/AIUI/components/scroll-view): A view container that supports horizontal or vertical scrolling.
- [Swiper](/AIUI/components/swiper): Organizes paged content with `swiper` and `swiper-item`.
- [Card](/AIUI/components/card): Composes a cover, title, body, and footer.

## Date Components

- [Calendar](/AIUI/components/calendar): Displays month, week, and schedule information.

## Basic Content

- [Text](/AIUI/components/text): Displays plain text content.
- [Icon](/AIUI/components/icon): Draws icons with a text font.
- [ErrorState](/AIUI/components/error-state): Displays empty, exceptional, or error states.
- [Streamdown](/AIUI/components/streamdown): Renders streaming Markdown content.
- [Table](/AIUI/components/table): Renders columns and row data as a table.
- [TimedText](/AIUI/components/timed-text): Highlights text ranges synchronized to playback.

## Semantic Content

- [P](/AIUI/components/p): Organizes paragraphs and inline content.
- [Header](/AIUI/components/header): Displays a content heading.
- [Blockquote](/AIUI/components/blockquote): Displays quoted content.
- [List](/AIUI/components/list): Organizes list items.
- [ListItem](/AIUI/components/list-item): Displays one list item.
- [B](/AIUI/components/b): Marks bold content.
- [I](/AIUI/components/i): Marks italic content.
- [Snippet](/AIUI/components/snippet): Displays inline or block code.
- [Formula](/AIUI/components/formula): Displays inline or block mathematics.

## Form Components

- [Button](/AIUI/components/button): A clickable button component.
- [Input](/AIUI/components/input): A single-line text input.
- [Textarea](/AIUI/components/textarea): A multiline text input.
- [Switch](/AIUI/components/switch): A switch and checkbox control.

## Media Components

- [Image](/AIUI/components/image): Displays image content.
- [Video](/AIUI/components/video): Plays video and reports playback events.
- [LottieView](/AIUI/components/lottie-view): Renders Lottie animation assets.

## Location Components

- [Map](/AIUI/components/map): Draws maps from MVT tiles.

## Canvas & Chart

- [Canvas](/AIUI/components/canvas): Provides a 2D drawing context and custom rendering capabilities.
- [Chart](/AIUI/components/chart): Renders data visualizations.

## AI Components

- [A2UI](/AIUI/components/a2ui): Generates interfaces from structured Agent commands.
