# AIUI快速入门

### 一、初始化AIUI项目

#### **1.在设备终端（terminal）输入**

```
npm create @yodaos-pkg/aiui-agent@latest my-agent
```

![image.png](../../image/quickstart/image.png)

```
cd my-agent #进入名为 my-agent 的文件夹
ls #列出当前文件夹里的文件和子文件夹
```

![image.png](../../image/quickstart/image%201.png)
