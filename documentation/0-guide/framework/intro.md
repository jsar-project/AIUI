# 介绍

AIUI 智能体框架的核心，不只是“把页面渲染出来”，而是把它作为一套意图驱动开发框架来组织。开发者需要定义智能体要承接什么样的用户意图、这些意图如何被处理，以及最终通过什么交互形态把反馈返回给用户；运行时再把这些部分串成一条完整链路。

下面这个交互式说明会从两个角度帮助你理解 AIUI 框架：

- 意图到反馈的完整链路由哪些部分组成
- 一个 Page 或 Widget 更新在运行时是怎么发生的

## 核心概念

AIUI 采用逻辑层与视图层分离设计，但这个分层并不是孤立存在的，而是和智能体描述、应用入口、Page、Widget 与 Agent Worker 一起协同工作：

1. **智能体描述 (Agent Description)**：由 `AGENTS.md` 定义智能体的身份、描述、能力和系统指令，决定平台如何理解这个智能体应当承接哪些意图。
2. **智能体入口 (Application Entry)**：由 `app.json` 声明 Page、Widget、Agent Worker 和全局配置，决定应用包含哪些入口与任务。
3. **逻辑层 (Logic Layer)**：负责解释用户操作、处理业务逻辑、调用 API 和管理数据状态。Agent Worker 可以承担不依赖某一个界面的共享任务。
4. **视图层 (View Layer)**：Page 承载完整交互，Widget 提供便于快速查看或操作的小尺寸界面；两者都可以使用数据绑定、组件和样式。

这种架构不仅能提供流畅的界面更新能力，也让开发者能够把“智能体要承接什么意图”“用 Page 还是 Widget 展示”“哪些任务需要共享”“界面如何反馈”拆开组织。
