# 智能体框架

AIUI 是一套面向智能体的意图驱动开发框架。它关注的不只是把界面渲染出来，或者把页面逻辑跑起来，而是把用户意图组织成完整的产品流转过程：智能体理解意图、选择合适的交互形态、执行所需逻辑，并将结果持续映射成界面反馈。

在实现层面，AIUI 主要围绕两个核心层次展开：

- **逻辑层**：负责理解和承接意图，处理应用、Page、Widget 和 Agent Worker 的状态、API 调用与事件。
- **视图层**：通过 Page 或 Widget 呈现信息、收集操作输入，并把状态变化映射成可见反馈。

但 AIUI 的框架核心并不只是把逻辑和 UI 分开。在一个真实的智能体项目中，它还会和这些部分协同工作：

- `AGENTS.md`：定义智能体的身份、目标、能力与行为边界
- `app.json`：声明 Page、Widget、Agent Worker 和全局配置
- Page 与 Widget：分别承载完整交互和快速查看的小尺寸界面
- Agent Worker：管理不依赖某一个界面的共享任务

这些部分共同构成了一条从 **意图理解** 到 **交互编排** 再到 **界面反馈** 的完整链路。

## 你将学到什么

本章节会从四个角度帮助你理解这套意图驱动框架：

- **介绍**：理解 AIUI 如何把意图、运行时与界面组织成一套完整框架。
- **分类**：理解对话式 AIUI 和沉浸式 AIUI 这两种意图承载形态，以及它们各自适合的场景。
- **逻辑开发**：了解如何围绕用户意图组织 Page、Widget 和 Agent Worker 的生命周期、状态和业务逻辑。
- **用户界面（UI）开发**：了解如何使用 WXML、WXSS 和 `.ink` 构建 Page 与 Widget。

## 推荐阅读路径

- 如果你刚接触 AIUI，建议先阅读 **介绍**，理解为什么 AIUI 的核心是“意图驱动”，而不只是“页面驱动”。
- 然后阅读 **分类**，判断你的产品应该用什么交互形态来承载用户意图。
- 接着阅读 **逻辑开发**，理解意图如何被转化为状态、生命周期和业务行为。
- 最后阅读 **用户界面（UI）开发**，把意图驱动的逻辑连接到具体界面上。

Widget 和 Agent Worker 的完整配置与示例，分别参阅 [Widget 开发](/AIUI/framework/open-agent-format-widget) 和 [Agent Worker 开发](/AIUI/framework/open-agent-format-agent-worker)。
