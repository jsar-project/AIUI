Rokid AIUI — a luminance & line system

A visual language for 480 × 352 px single-green transparent AR displays (RokidGlasses1 / RokidGlasses2). One green channel at controlled luminance, rendered as thin structural lines, sparse fills, compact technical typography, and spatial relationships — closer to a scientific instrument than a stack of application cards.

06 — Depth

Three restrained levels

No general-purpose drop shadow. Depth comes from transparent tiers, local tint, and frame strength.

0 · open fieldTransparent / black, no boundary. Default canvas.
1 · local grouping06% tint or 24% frame. Secondary panel, input grouping.
2 · active grouping12% tint + 72% frame. Selected / focused region.
07 — Do & Don't

Discipline

Do
  • Reserve full green for focus and key values.
  • Use 1px lines and low visual mass.
  • Prefer open list rows over repeated cards.
  • Pair every state with text + geometric cue.
  • Use monospace for logs, IDs, coordinates.
Don't
  • Rebuild the UI as a stack of glowing cards.
  • Default every container to a 12px radius.
  • Use 2–4px borders as normal chrome.
  • Encode state only through brightness.
  • Introduce a second hue.
