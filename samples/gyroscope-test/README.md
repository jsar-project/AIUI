# 陀螺仪测试

这是一个独立、最小化的 Rokid AIUI 真机诊断示例，仅包含一个测试页面。

> 项目名称沿用“陀螺仪测试”，实际读取的是 `AbsoluteOrientationSensor` 输出的绝对方向四元数，而不是 `Gyroscope` 的三轴旋转角速度。

## 测试内容

- 请求 60Hz 的 `AbsoluteOrientationSensor` 数据。
- 显示实测采样频率和累计样本数。
- 显示原始四元数和 X、Y、Z 三轴旋转向量。
- 判断当前动作的主导设备轴。
- 使用固定坐标轴、中心圆环和动态十字准星观察方向映射。
- 显示回中误差，2°以内视为回到中心。
- 解析并显示 AIUI、Ink、YodaOS、CPU 架构和绝对方向接口状态。
- 按确认键以当前姿态重新校准中心。

## 真机测试方法

1. 正视前方启动项目，等待页面显示“绝对方向数据读取正常”。
2. 按确认键重新建立中心基准。
3. 依次左转、右转、抬头、低头，观察准星方向和主导轴。
4. 每次动作后回正，观察准星能否回到中心圆环以及误差是否在2°以内。
5. 连续测试一分钟，观察频率是否稳定、是否产生累计漂移。

## 项目边界

项目不包含游戏状态机、目标生成、音频、素材、存储或网络逻辑。
